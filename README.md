# Bayesian-a: Log-Odds 占据栅格地图

纯 Go 标准库实现的基于对数几率（log-odds）的占据栅格地图，附带过度自信检测与单文件 HTML 回放。用于演示和检测数值稳定性问题与传感器逆模型误用。

## 运行

```sh
go test ./...        # 运行全部自动化测试
go run ./cmd/mapgen  # 运行模拟，生成 map.html
open map.html        # 浏览器中逐帧回放（无需任何服务）
```

## 对数几率模型

每个栅格维护占据概率 $p$ 的对数几率 $l = \log\frac{p}{1-p}$。贝叶斯更新在 log-odds 空间变为**加法**：

$$l_t = l_{t-1} + \log\frac{p(z\,|\,occ)}{1 - p(z\,|\,occ)} - \log\frac{p_0}{1-p_0}$$

取先验 $p_0 = 0.5$ 时最后一项为 0，每次观测只需累加一个传感器模型增量。概率通过数值稳定的 logistic 函数还原（`Probability`，对 $|l|$ 很大时也不会溢出）。

## 传感器逆模型假设

波束式测距仪的标准简化假设（`SensorModel`）：

- 波束**终点**栅格以 $p_{occ}=0.7$ 为占据（增量 `LOcc = log(0.7/0.3) ≈ +0.85`）；
- 波束**穿过**的栅格以 $p_{free}=0.4$ 为占据（增量 `LFree ≈ -0.41`）；
- 各栅格条件独立，各次测量条件独立（这正是该模型已知会过度自信的原因，也是本项目的检测对象）。

`OverconfidentSensorModel`（$p_{occ}=0.97$）是故意不合理的对照组：单次观测增量 ±3.48，两次观测即把栅格推到 p≈0.999。

## 数值边界处理（饱和）

log-odds 累加器钳制在 `[LMin, LMax] = [-12, +12]`（`Grid.LMin/LMax`，可配置）：

- 极端概率被限制在约 $[6\times10^{-6},\, 0.999994]$，**永远不会**达到精确的 0/1，也不会出现 `Inf`/`NaN`；
- 饱和后单次相反观测仍产生一个完整模型步长的影响（$l \leftarrow L_{max} + l_{free}$），不会被无限大的累加值吞没；
- 长期重复观测收敛到饱和边界处的稳定不动点（测试 `TestLongRunConvergence` 验证 200 次扫描后概率不再变化）。

## 测距线更新顺序

`IntegrateScan` 对一帧扫描内所有波束统一处理，顺序是关键：

1. Bresenham 走线（`LineCells`）求出每条波束经过的栅格，**终点除外**的标记为空闲，终点标记为占据；
2. 若某栅格既是一条波束的终点、又位于另一条波束的自由路径上，将其从空闲集合中删除——命中证据优先；
3. 先应用全部空闲更新，再应用全部占据更新。

因此终点栅格绝不会被自己（或同帧其他）波束的自由空间更新覆盖。

## 过度自信检测

`Detector` 在每次扫描后检查所有栅格：若某栅格在 **≤3 次观测**内概率即达到 ≤0.02 或 ≥0.98，记为一次异常收敛事件（每栅格只报一次）。阈值经过标定：合理模型需要 ≥5 次一致观测才能达到 p=0.98，因此不会误报；过度自信模型 2 次观测即触发。`SaturatedFraction` 给出全图饱和栅格比例作为整体指标。

模拟结果（64×64，72 帧，噪声 σ=0.25 格）：合理模型 **0** 次异常；过度自信模型 **2451** 次异常，最终 82% 的已观测栅格处于极端概率（合理模型为 25%，且均为大量一致观测后的合法收敛）。

## HTML 回放

`cmd/mapgen` 用 `go:embed` 内嵌模板，把全部帧（概率量化为字节、base64 编码）与异常事件嵌入单一 `map.html`。前端为原生 HTML/CSS/JavaScript + canvas，无任何框架或图形库：逐帧播放/暂停/步进/拖动，左右对照两种模型，颜色深浅表示占据概率（灰=未知，白=空闲，红=占据），黑点为真实障碍物，底部实时列出异常收敛事件。

## 测试覆盖（`occupancy/grid_test.go`）

| 测试 | 覆盖需求 |
|---|---|
| `TestSaturationNoOverflow` | 10⁵ 次重复观测钳制不溢出、单次相反观测仍有明确影响 |
| `TestRayFreeSpaceAndEndpoint` | 测距线自由空间/终点占据判定，终点不受自身自由更新污染 |
| `TestEndpointBeatsCrossingFreeRay` | 终点与交叉波束自由路径冲突时占据优先 |
| `TestOverconfidenceDetection` | 高置信度参数下检测异常收敛，合理模型零误报 |
| `TestLongRunConvergence` | 长期观测收敛到稳定值、交替观测永久有界 |
| `TestSimulate` | 模拟确定性、噪声数据下过度自信模型必触发异常 |
